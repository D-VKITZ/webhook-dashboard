# Webhook Dashboard

Webhook Dashboard — Event Processing und Webhook Management.

## Features

- Real-time webhook event processing and visualization
- Event log with filtering and search
- Payload inspection and replay capability
- Webhook endpoint management
- Integration with n8n and NanoChat bridge

## Tech Stack

Node.js · JavaScript ES6+ · WebSocket · Express

## Quick Start

```bash
git clone https://github.com/D-VKITZ/webhook-dashboard.git
cd webhook-dashboard
npm install
npm start
```
